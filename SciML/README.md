# ES98E: Scientific Machine Learning

Learning outcomes

*  Understand and apply Bayesian inference to infer model parameters from data
*  Understand and apply Gaussian process regression to build surrogate models for computational codes
*  Understand and apply deep neural networks to practical problems in scientific computing
*  Understand how to combine neural network and mechanistic models to perform scientific machine learning
*  Understand how approximate inference techniques work and when they can be used
