 # MSc in Predictive Modelling and Scientific Computing

This repository contains any of the code I wrote whilst studying my postgraduate degree. This masters focused on applied mathematics, statistics, and algorithmic approaches to large-scale computational modelling.

Core modules include: 
* Predictive Modelling (Functional Analysis, Bayesian Inference and Uncertainty Quantification), 
* Scientific Machine Learning, 
* Numerical Algorithms & Optimisation,  
* Particle-based Modelling (Statistical Physics), 
* High Performance Computing (OpenMP, MPI, SLURM, Distributed ML), 
* Advanced Machine Learning.
* Group Project
* Thesis
